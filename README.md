# HR Calc — калькулятор стоимости сотрудника

Веб-приложение (PWA) для консалтинговой компании: по сумме **на руки** считает начисление (gross),
налоги и взносы сотрудника и работодателя, а также полную стоимость сотрудника с учётом
дополнительных затрат компании. Работает на десктопе и на телефоне, устанавливается как приложение,
после первой загрузки работает офлайн.

## Что считает

**Доход сотрудника (нетто):**
- оклад на руки;
- премия за участие в проекте: ставка премии при 100 % загрузки × фактическая загрузка в месяце (%).

**Юрисдикции и формы оформления (ставки 2026 г., редактируются в интерфейсе):**

| Страна | Режим | Удержания с сотрудника | Отчисления работодателя |
|---|---|---|---|
| Россия | ТД, общий тариф | НДФЛ 13–22 % (прогрессивная шкала) | Взносы 30 % до предельной базы 2 979 000 ₽/год, 15,1 % сверх; травматизм 0,2 % |
| Россия | ТД, ИТ-компания | НДФЛ 13–22 % | Взносы 7,6 % до базы, 15 % сверх; травматизм 0,2 % |
| Россия | ГПХ | НДФЛ 13–22 % | Взносы 30 % / 15,1 %, без травматизма |
| Казахстан | ТД, ОУР | ОПВ 10 %, ВОСМС 2 %, ИПН 10 % (15 % с превышения 8 500 МРП/год), вычет 30 МРП | ОПВР 3,5 %, ООСМС 3 %, СО 5 %, СН 11 % (за минусом СО) |
| Казахстан | ТД, упрощёнка | то же | ОПВР, ООСМС, СО; СН не уплачивается |
| Казахстан | ГПХ | ОПВ 10 %, ВОСМС 2 %, ИПН 10 % (без вычета) | ОПВР 3,5 % |
| Узбекистан | ТД, стандарт | НДФЛ 12 % (в т. ч. ИНПС 0,1 %) | Соцналог 12 % |
| Узбекистан | ТД, IT Park | НДФЛ 7,5 % | Соцналог 0 % |

Пределы баз в Казахстане: ОПВ и ОПВР — 50 МЗП, ВОСМС и ООСМС — 10 МЗП, СО — от 1 до 7 МЗП
(МРП 4 325 ₸, МЗП 85 000 ₸).

**Дополнительные затраты компании** (не входят в зарплату, приводятся к месяцу):
связь, ДМС, обучение, оборудование (стоимость / срок амортизации в месяцах).

**Результат:** на руки, начислено, удержания, отчисления работодателя, ФОТ с отчислениями,
полная стоимость в месяц и в год, коэффициент «стоимость / на руки», доля налогов и взносов в ФОТ.

### Допущения
- Доход считается равномерным в течение года: годовые пороги (прогрессивная шкала НДФЛ/ИПН,
  предельные базы по взносам) применяются как 1/12 в месяц.
- Социальные вычеты, льготы по инвалидности, пенсионерам и т. п. не учитываются.
- Обратный расчёт (нетто → gross) делается численно, точность до копейки.

## Запуск

Сборка не нужна — это статические файлы.

```bash
npm test      # юнит-тесты ядра расчёта (node --test)
npm start     # локальный сервер: http://localhost:8080
```

Для установки как PWA (кнопка «Установить приложение» в шапке) сайт должен открываться по HTTPS
или с `localhost`. В репозитории есть workflow `.github/workflows/pages.yml`: при пуше в `main`
прогоняет тесты и публикует приложение на GitHub Pages (в настройках репозитория
Settings → Pages → Source: GitHub Actions).

## Структура

```
index.html            разметка
css/styles.css        стили (светлая/тёмная тема, мобильная и печатная вёрстка)
js/params.js          режимы и параметры 2026 г. (ставки, пороги, МРП/МЗП)
js/calc.js            ядро расчёта: computeFromGross, grossUp, calculate
js/app.js             интерфейс, сохранение в localStorage, PWA
sw.js                 service worker (офлайн-кеш оболочки)
manifest.webmanifest  манифест PWA
test/calc.test.mjs    тесты ядра
server.mjs            статический сервер для локального запуска
```

## Как обновить ставки на новый год

Значения по умолчанию — в `js/params.js` (`DEFAULT_PARAMS`). После изменения увеличьте
`VERSION` в `sw.js`, чтобы установленные приложения подхватили обновление. Пользователь также
может временно переопределить любую ставку в панели «Параметры расчёта» (хранится в браузере).
